# Uninstall

```text
TradeCopia-Setup-0.1.0-alpha.7.exe --uninstall
```

Removes TradeCopia app binaries, Start Menu shortcut, and TradeCopia-owned files under NinjaTrader `bin\Custom` (`TradeCopia.*` only). NinjaTrader workspaces, accounts, and unrelated AddOns are left intact. Local journal data is preserved by default.
